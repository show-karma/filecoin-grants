# Milestone review

For one milestone a team marked complete. The packet informs the reviewer who verifies it on app.filpgf.io; it does not decide.

1. **Find it**: Karma's pending-verification queue (see filpgf-read-karma) lists each milestone with `projectUid` and `grantUid`. Read the project's grants and pick the milestone.
2. **Criteria**: read the application by its reference number. The milestone's deliverables and success criteria are in `applicationData`, not on the milestone.
3. **Evidence**: follow every link in the milestone's completion update. Check code claims in git (commits, merged PRs, releases in the milestone window) and metric claims in OSO.
4. **Rate**: each deliverable as Found, Partial, Not found or Can't verify, with the link.
5. **Assess**: up to five open questions the reviewer should put to the team. No verdict and no recommendation.
