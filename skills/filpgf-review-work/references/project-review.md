# Project review

For a funded project as a whole, at an as-of date.

1. **Find it**: the project's grants and milestones from Karma (filpgf-read-karma). For a Kernel project, also its indicators and its entry in the Kernel projects list.
2. **Funding**: committed and disbursed from Karma.
3. **Delivery**: every milestone's status against its due date.
4. **Measured**: the Kernel indicators and readings, and OSO metrics (through OSO's MCP server) via the project's `osoProjectSlug`. Compare against the SLA or target the project committed to.
5. **Assess**: three or four sentences: is the project delivering what it was funded for, and what should happen next (continue, follow up on named items, or escalate). Label it a draft for the reviewer.
